# Security policy

## Supported versions

workclock is pre-1.0. Security fixes go into the latest minor release only.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Karthik-beta/workclock/security/advisories/new),
not in a public issue.

You can expect an acknowledgement within 7 days. Once a fix is released, the
advisory is published with credit to the reporter unless you ask otherwise.
