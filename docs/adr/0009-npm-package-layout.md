# 0009. npm package layout and wasm-pack targets

- Status: Accepted
- Date: 2026-10-23

## Context

wasm-pack builds one JavaScript wrapper per target, and each target loads the
WebAssembly module differently:

- `nodejs` reads the `.wasm` file synchronously when imported. It works in
  Node without a bundler or flags.
- `bundler` imports the `.wasm` file as a module, which Vite, webpack,
  Rollup and esbuild resolve. Node cannot load it without experimental flags.
- `web` fetches the `.wasm` file after an explicit `await init()`. It works in
  browsers without a bundler, and in Deno.

The npm `exports` field can send each runtime to a different file through
conditions (`node`, `browser`, `default`) and subpaths.

## Decision

Ship all three builds in one package, under `pkg/node`, `pkg/bundler` and
`pkg/web`, behind small hand-written entry modules:

| Import | Condition | Build |
|---|---|---|
| `workclock` | `node` | `nodejs` |
| `workclock` | `browser`, `default` | `bundler` |
| `workclock/web` | any | `web`; call `init()` first |

- Every entry has its own `.d.ts`, listed under `types` in its condition.
- `files` limits the tarball to the entries, the three builds, the README,
  LICENSE and NOTICE. `prepack` copies LICENSE and NOTICE from the repository
  root.
- `sideEffects` lists the bundler build's wrapper, which instantiates the
  module when imported, so bundlers keep it; everything else is free of side
  effects. This matches the `package.json` that wasm-pack generates for that
  target.
- `engines` requires Node 22 or later, the oldest Node release line still
  maintained.

## Consequences

- One `npm install workclock` works in Node, bundled browser apps, plain
  browser modules and Deno, with the right loader chosen automatically.
- The tarball carries three copies of the `.wasm` file. Each runtime loads
  only one, so this costs download size, not runtime size.
- The entry modules are the only JavaScript written by hand, apart from the
  error classes; the API itself is generated by wasm-bindgen from Rust.
